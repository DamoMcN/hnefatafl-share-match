Hnefatafl Share Match

A small web page that replays a shared Hnefatafl match in any browser. Nothing to install.

Viewer: https://damomcn.github.io/hnefatafl-share-match/

How it works

Hnefatafl is a free Viking board game. Its Share match button packs the whole game into a link: the start position, every move, the pieces each move captured, the move grades and the options you chose. Opening the link shows the match here.

The match is stored in the part of the link after the #. Browsers never send that part to a server, so nothing is uploaded or stored anywhere.
The page is a single file, index.html, with no build step and no libraries.
What viewers can do
Step through the game with the buttons, the slider, the move list or the left and right arrow keys, or press Play.
See the played move and the better move as arrows.
See a grade badge (Best, Good, ?!, ?, ??) beside the moved piece, with a short sound.
Turn sound and arrows on or off.

The person sharing chooses the defaults: grades, badges, sounds, arrows, where the match opens, autoplay, speed and whether names show.

Browser support

A recent Chrome, Edge, Safari (16.4 or newer) or Firefox. Older browsers show a message instead of the match.
